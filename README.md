# 📊 Fitness Tracker Data Analysis

This project presents a complete data analysis workflow for fitness tracker devices, including data cleaning, exploratory data analysis (EDA), and an interactive Power BI dashboard.

---

## 📁 Project Files

- `Fitness_trackers.csv` → Raw dataset  
- `Final_Cleaning_Fitness_trackers.csv` → Cleaned dataset after preprocessing  
- `fitnessTracer.ipynb` → Jupyter Notebook for data cleaning and analysis  
- `Fitness Tracker.pbix` → Power BI dashboard file  

---

## 📌 Project Overview

This project analyzes fitness tracker devices to extract meaningful business insights such as:

- Pricing trends (original vs selling price)
- Most popular brands in the market
- Impact of materials and display types on pricing
- Battery life comparison across brands
- Device features like color, rating, and discounts

---

## 🛠️ Tools & Technologies

- Python (Pandas, NumPy)
- Jupyter Notebook
- Power BI
- Data Visualization
- Data Cleaning & Preprocessing

---

## 🔄 Workflow

### 1. Data Cleaning
- Removed duplicates and missing values  
- Standardized inconsistent data formats  
- Handled categorical inconsistencies  
- Created final clean dataset  

### 2. Exploratory Data Analysis (EDA)
- Price distribution analysis  
- Brand-wise comparison  
- Material vs price relationship  
- Battery life insights  
- Display type analysis  

### 3. Power BI Dashboard
An interactive dashboard was built including:

- KPI Cards (Total Price, Average Price, Discounts, Device Count)  
- Brand performance visualization  
- Strap material analysis  
- Display type impact  
- Battery life comparison  
- Color distribution analysis  

---

## 📊 Key Insights

- Certain brands dominate in total sales value  
- Silicone and stainless steel straps are the most popular  
- AMOLED displays contribute to higher selling prices  
- Battery life varies significantly between brands  
- Black color devices are the most common in the dataset  

---

## 🚀 How to Use

1. Clone the repository  
2. Open `fitnessTracer.ipynb` in Jupyter Notebook to explore analysis  
3. Open `Fitness Tracker.pbix` in Power BI Desktop for dashboard  
4. Explore datasets in CSV files
